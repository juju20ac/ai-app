  As a user, I want to be able to update the status of a DBT request to "Archived" or "Deleted" so that I can better manage and organize inactive or unwanted requests.

  Summary: Implement Archived and Deleted statuses for DBT requests

2. Allow resubmitting AI Rules and creating a new DBT request when status is Archived or Deleted
  As a user, I want to be able to resubmit AI Rules and create a new DBT request if the previously submitted rule has a status of "Archived" or "Deleted," so that I can re-initiate workflows without being blocked by inactive or removed requests.

  Summary: Enable AI Rule resubmission and new DBT request creation for Archived/Deleted rules
  Description:
    Update the AI Rules workflow to permit rule resubmissions when the current rule's DBT request status is set to "Archived" or "Deleted." Triggering a resubmission should allow the user to create a new DBT request.
